# Feliz cumpleaños, mi Junior ❤️

Página de cumpleaños romántica con detalles visuales inspirados en las siete esferas de Dragon Ball. Incluye la historia y el mensaje para Junior, animaciones de corazones, navegación por capítulos y un deseo interactivo.

Abre `index.html` en un navegador o publica la raíz del repositorio con GitHub Pages. No necesita dependencias ni archivos personales de la versión anterior. Las fuentes de Google Fonts son opcionales; si no cargan, se usan fuentes locales.
