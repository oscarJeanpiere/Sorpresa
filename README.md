# 💗 Para Víctor

Una pequeña página web romántica e interactiva hecha con HTML, CSS y JavaScript.

## 📁 Antes de subirla

Coloca tus archivos en:

- `img/foto1.jpg`
- `img/foto2.jpg`
- `img/foto3.jpg`
- `img/snoopy.png`
- `img/shinobu.png`
- `audio/musica.mp3` (opcional)

**Importante:** si no agregas las imágenes, la página seguirá funcionando, pero aparecerán espacios vacíos.

## 🚀 Publicarla en GitHub Pages

1. Crea un repositorio en GitHub, por ejemplo `victor-amor`.
2. Sube `index.html`, `style.css`, `script.js` y las carpetas `img` y `audio`.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera unos minutos.
7. GitHub te dará el enlace de tu página.

## 🎵 Música

La música no viene incluida por derechos de autor. Si quieres usar una canción, coloca tu propio archivo como:

`audio/musica.mp3`

En algunos navegadores la música no puede comenzar automáticamente; por eso hay un botón `♫` abajo a la derecha.

## ✨ Personalización

Todo el texto está directamente en `index.html`, por lo que puedes cambiar nombres, frases y preguntas.

Las animaciones están en `style.css` y `script.js`.
